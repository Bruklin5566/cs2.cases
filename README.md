# CS2 CASES — тестовый прототип

Откройте `index.html` в браузере.

## Работающие элементы
- Навигация по секциям.
- Открытие демо-кейсов с результатом.
- Мини-игры с демонстрационным результатом.
- Проверка формата торговой ссылки (ссылка не сохраняется и не отправляется).
- Тестовый локальный профиль по кнопке входа.
- Модальные окна закрываются кнопкой, кликом вне окна или клавишей Escape.

## Важно про вход Steam
Кнопка «Войти в демо» создаёт только локальный тестовый профиль. Она не подключает Steam, не читает инвентарь и не даёт возможность обмена. Настоящая авторизация требует backend с проверкой Steam OpenID и разрешённого callback URL. Никогда не запрашивайте и не храните пароль Steam на своём сайте.

## Перед production
Потребуются backend, база данных, серверная проверка результатов, защищённые сессии, проверка API торговой площадки и юридическая проверка правил. Предметы можно передавать только через прозрачный обмен, подтверждённый владельцем.
